# mc3_nx v1.0.1

Controls update: A for the on-screen prompts, the right stick for the drag bars, + to skip cutscenes, and quitting
from the main menu.

## New

- **A uses the prompt on screen**: a computer, a door, a bomb, a weapon on the ground, a grenade to throw back, a
  melee counter, a QTE. It works wherever the prompt is, including the ones that follow an object on screen. The port
  gives the game the same request the prompt's button would, and only while the prompt can really be used.
- **Quick-time bars filled with a finger**: the touch screen works as before, and the right stick is the finger too,
  for docked play (flick it the way you would swipe, again and again).
- **+ skips cutscenes**, as the ">>" button in the corner. It no longer pauses the game when the cutscene ends.

## Fixed

- **Quit from the main menu** (B, then Yes): the game stayed open. It now closes cleanly.

## Update

Replace `sdmc:/switch/mc3_nx/mc3_nx.nro` with the new one and start the game from the same HOME-menu icon. Saves and
settings stay. First install: see the [README](https://github.com/Kaays/mc3_nx#install).

## Known issues

- Heavy breathing after a sprint can go on until the next death or loading screen.
- No multiplayer (Gameloft's servers are gone).
